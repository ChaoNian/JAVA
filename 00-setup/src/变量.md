# 变量

```
                     Java变量
                         |
        --------------------------------
        |                              |
     数据类型                       生命周期
        |                              |
  ----------------              ----------------
  |              |              |              |
基本类型       引用类型      局部变量       成员变量
                                 |
                          ----------------
                          |              |
                       实例变量      静态变量
```

Java 变量分类，本质是在训练你如何管理数据的**归属、生命周期和访问范围**。
