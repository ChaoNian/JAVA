# 01 · 语法与面向对象

**建议：5 周** · 先完成 [`00-setup`](../00-setup/README.md)。

## 目标

用类、对象、封装把问题拆开，而不是把所有逻辑塞进 `main`。

## 要学什么

- 类型系统：基本类型 vs 引用类型、装箱拆箱、`String` 不可变
- 控制流、方法、重载、可变参数、静态成员
- 类与对象、构造、`this`、访问控制、包
- 继承、多态、抽象类、接口；组合优先于继承
- `equals` / `hashCode` / `toString` 契约；枚举

## 练习题（写入本目录 `src/`）

建模「银行账户」或「图书借阅」：多个类、继承或接口各用一次，禁止全塞 `main`。

建议拆成多次提交式练习，每次一个文件：

- `Ex01EqualsVsEq.java` —— 为什么字符串不能用 `==` 比较内容
- `Ex02ImmutableString.java` —— `s.concat` 不会改原来的 `s`
- 一个小领域模型（账户 / 借阅）

## 过关标准

能讲清值传递、引用传递，以及为什么 `String` 比较要用 `equals`。

## 这一阶段先别碰

设计模式全集、反射。
